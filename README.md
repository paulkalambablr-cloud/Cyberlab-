# **MODULE 1: Les fondamentaux de la cybersécurité**

## **Définition**

La cybersécurité est un ensemble de solutions déployées pour sécuriser les systèmes, les réseaux et les données. Cette sécurité est basée sur la triade **CIA** dont: **C**(Confidentialité: Pas d'accès aux informations sans autorisation), **I**(Intégralité: Pas de modification des informations sans autorisation), **A**(Disponible: Les informations doivent être disponibles lorsqu'on en a besoin) 

## **L'actif**

L'actif c'est ce que l'on protège, ça peut être un serveur ou un ordinateur 

## **La vulnérabilité**

La vulnérabilité c'est le point faible lié à un actif, ça peut être un mot de passe faible

## **La Menace**

La menace c'est la personne ou l'organisation détentrice des outils pour exploiter la vulnérabilité 

## **L'incident**

L'incident c'est **L'actif + La vulnérabilité x La Menace**. C'est l'ensemble de ces trois éléments qui crée un incident
